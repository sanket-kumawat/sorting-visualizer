About

Repeatedly swaps adjacent out-of-order pairs.

Bubble sort is a simple comparison-based algorithm that repeatedly checks neighboring values and swaps them when they are in the wrong order.

  • Make repeated passes through the array.
  • Compare adjacent values and swap them when the left value is larger.
  • Each pass places the largest remaining value at the end.
  • Stop early when a complete pass makes no swaps.
